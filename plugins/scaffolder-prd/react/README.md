# Scaffolder AI PRD (Frontend)

Backstage UI for the blueprint-only PRD translation milestone.

- Submits and replays inline PRD delivery blueprints.
- Displays parallel PM, Engineer, and Writer step lanes.
- Displays cited epic/stories, template plan, documentation outline, and limitations.

The current backend does not expose approval, ticket creation, Scaffolder task
execution, or documentation publishing. This UI deliberately contains no controls
for those unavailable actions.
